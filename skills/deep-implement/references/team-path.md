# Parallel implementation

Use actual available native delegation only when selected and consistent with the user's model/mode choice. Preserve the current model inline by default. An environment variable is not proof that a host tool exists.

One target session has one active slice and one governed write/evidence window. Workers may prepare independent patches for the controller's serialized runtime application, or execute in independently isolated sessions/worktrees. A cluster ID does not authorize simultaneous changes to shared session state.

Pass each worker the exact state/plan identity, assigned slice IDs, declared scopes, dependency evidence and requested model/effort. Read `${CLAUDE_PLUGIN_ROOT}/agents/implement-slice-worker.md` for its contract. Every execution site uses runtime producers and publication; no permission bypass or handcrafted child completion receipt.

Preserve partial failures and verified healthy siblings. The controller authenticates each result before continuing dependency-ready work. Do not spawn another worker to duplicate a still-running operation or overwrite an active slice's manifest window.
