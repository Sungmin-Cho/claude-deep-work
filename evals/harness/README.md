# Harness smoke pilot

The frozen live subset is two tasks × three variants × two models × one trial = 12 attempts. Every attempt has the same task budget (600 seconds), workspace-write sandbox and task permissions. Network capability is identical across variants and is authorized only for model inference/review, not external product effects. Baseline uses the task and ordinary host instructions; minimal adds an outcome/scope/verification paragraph; current reads and executes the actual plugin entry. Native user/plugin hooks and the cached deep-work plugin are disabled uniformly to avoid mixing an installed older version with the candidate. The current treatment executes the actual candidate skill and public runtime; candidate hooks are validated separately through their registered hook entry. This pilot does not establish native-client hook loading/integration quality. Other global host context is shared across variants and remains a potential source of interference.

Run `node evals/harness/run.js freeze /absolute/evidence-directory` after the candidate is stable. The returned attempt IDs are then run individually with `node evals/harness/run.js attempt /absolute/evidence-directory <attempt-id> /absolute/codex`. Run sequentially or with a fixed documented concurrency limit. An existing attempt is never overwritten. Candidate drift requires a new evidence directory; retain earlier attempts and explain the revision.

The grader checks product files independently of model claims. Its oracles and controller records are outside the agent's writable workspace. The regression module runs in a bounded child; this is not a generic malware sandbox. Runtime cases in the six-family bank require the public-runtime test suite and are not counted as live model trials. Requested model, observed provider metadata, final claim, usage, timeout, output overflow and termination status remain distinct. Missing identity or cost is null. A successful product check does not itself prove that the current treatment completed every plugin phase.

These are smoke observations. Twelve attempts cannot establish statistical efficacy or a general model ranking. Report all failed, unavailable and timed-out attempts, along with intervention compliance and actual runtime limitations.
